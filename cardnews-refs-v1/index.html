헤르메스 카드뉴스 — 디자인 레퍼런스

2026-06-05 · "좋은 카드뉴스"의 기준을 맞추기 위한 실제 사례 모음 · 방향: A·B·C·D 4스타일을 소재·컨셉에 맞게 모두 활용

① 우리가 쓸 4가지 스타일 (그때그때 적절히 선택)

A. 다크 + 볼드 타이포 + 그라데이션
테크·트렌디. 거대 타이포가 주인공, 그라데이션은 양념.
↳ overseas-tech에 잘 맞음 · Sprout 스타일
B. 화이트 + 에디토리얼 세리프 + 콜라주
감성·큐레이션. 매거진 무드, 넘버링 + 사진 콜라주.
↳ lifelore에 잘 맞음 · Canva 스타일
C. 컬러 배경 + 초대형 숫자/데이터
정보·팩트. 라벨칩 + 큰 숫자 + 출처 명기.
↳ painpoint에 잘 맞음 · Mailchimp 스타일
D. 사진 + 솔리드박스 미니멀
사진 위 텍스트는 솔리드 박스로 분리. 배경 사진은 본인 사진·스톡·AI배경·제품컷 등 활용처 다양(본인 사진은 그중 하나).
↳ 모든 컨셉 공용 · Mel Robbins 스타일

② 모든 사례에서 반복되는 공통 디자인 문법

  • 거대한 볼드 타이포가 주인공 — hook은 글자가 화면의 80~90%
  • 포인트 컬러 1개 — 다크/화이트 배경 + 강조색 하나(한 단어만 컬러)
  • 라벨 칩 — "HOT TAKE:", "Did you know?" 알약으로 맥락 표시
  • 사진은 양념 — 그라데이션·콜라주·하단배치, 절대 주인공 아님
  • 사진 위 텍스트는 솔리드 박스로 분리 — 가독성 1순위 규칙
  • 출처 명기 — 데이터 카드엔 "Source: …" (우리 provenance와 동일)
  • 페이지 인디케이터 + 브랜드 락업 — 1/8, 점, 하단 로고로 시리즈 통일
  • 숫자·넘버링 — 통계는 초대형 숫자, 리스트는 숫자 뱃지로 분리

③ 실전 레퍼런스 — 해외 정보형 캐러셀 (우리 컨셉에 가장 근접)

HOOKA
Sprout Social (2026-05)
hook의 정석. 라벨칩(HOT TAKE:) + 초대형 볼드 + 반전 메시지("Data doesn't drive decisions. Intelligence does.") + 한 구절만 그라데이션.
EVIDENCEC
Mailchimp
데이터 카드 + 출처 명기. "Did you know?" 칩 + 초대형 70% + 설명문 + "Source: …". → 우리 evidence role + verify_status·provenance와 정확히 일치.
HOOKA
Sprout Social (2026-05)
다크 + 그라데이션 양념. 큰 이탤릭 산세리프 + 그라데이션 인물카드 + "What's trending?" 버블. → composite+배경 양념의 좋은 예.
HOOKD
Mel Robbins
사진 + 하단 솔리드 박스. 인물 사진 위 흰 박스 3줄 + 1/8 + 손글씨 로고. 배경 사진은 본인·스톡·AI 무엇이든 가능 — 글자가 안 깨지는 게 핵심.
CONTEXT / TRENDB
Canva (2026-05, ♥2.7K)
에디토리얼 매거진 무드. 거대 세리프 "TRENDS SPOTTED" + 넘버링(01~05) + 사진 콜라주. → lifelore·overseas 트렌드 소개 카드 톤.
EVIDENCE / 나열D
Frank Body (2026-05)
2×2 그리드 + 중앙 솔리드 캡션. 4컷을 격자로, 중앙에 흰 박스 한 줄. → 여러 항목을 한 장에 나열하는 evidence 슬라이드.
사진형 / 쉼표D
Clearstem (2026-05)
미니멀 제품 사진. 흰 배경 + 정돈된 오브제, 텍스트 최소. → 글자 없이 사진만으로 호흡을 주는 슬라이드(캐러셀 중간 쉼표).

④ 한국 디자인 원칙 — Good vs Bad 교보재 (따라할 톤보다 '규칙' 학습용)

규칙: 가독성
elancer 블로그
사진 위 텍스트 = 솔리드 박스. Good은 하단 빨강 박스(읽힘), Bad는 사진 위 직접 흰 글자(안 읽힘). → 2-3 렌더 검증(contrast) 규칙의 근거.
규칙: 리스티클
elancer 블로그
항목은 숫자뱃지 + 개별 박스로 분리. Good은 1·2·3·4 뱃지로 끊고, Bad는 한 박스에 욱여넣음. → multi_topic·claim 나열 슬라이드 규칙.
개념도
elancer 블로그
개념은 도식 + 굵은 타이포. 골든서클(WHY·HOW·WHAT = 목적·과정·결과), 강한 보색 대비. → insight role(구조를 그림으로 설명).
